<h1 align="center">Integrated Pipeline for In Silico Discovery of HIV-1 Protease Inhibitors</h1>
<p align="center">
  <i>Этот проект представляет собой сквозной CADD-пайплайн структурного дизайна лекарств: от подготовки мишени и высокопроизводительного виртуального скрининга до обучения ML-моделей для предсказания аффинности связывания.</i>
</p>

## 1. Введение и биологическая мишень

* **Объект исследования:** Главная протеаза ВИЧ-1 — гомодимерный фермент, важный для жизненного цикла вируса.
* **Механизм действия:** Протеаза расщепляет вирусные полипротеины на функциональные белки и ферменты. Блокировка активного центра (каталитическая диада `Asp25`/`Asp25'`) останавливает репликацию вируса.
* **Цель проекта:** Разработать вычислительный пайплайн на базе машинного обучения для быстрого предсказания аффинности связывания лигандов, позволяющий ускорить поиск хитов без высоких вычислительных затрат на классический молекулярный докинг.

## 2. Этап I: Структурное моделирование и молекулярный докинг

* **Технологический стек:** AutoDock Vina, OpenBabel, Python `multiprocessing`
* **Подготовка мишени:**
  * Использована кристаллическая структура протеазы ВИЧ-1 (**PDB ID: 1HPV**).
  * Удалены молекулы растворителя ($H_2O$), добавлены полярные атомы водорода и рассчитаны частичные заряды для генерации результирующего PDBQT-файла.
* **Виртуальный скрининг (HTVS):**
  * Автоматизирован пайплайн докинга для **2000 потенциальных целевых лигандов**, полученных из базы данных ChEMBL.
  * **Оптимизация производительности:** Реализовано распараллеливание вычислений на 10 ядрах CPU через модуль `multiprocessing`, что обеспечило **8-кратное ускорение** работы скрипта.
  * **Параметры докинга:** Установлено значение `exhaustiveness = 8` (золотой стандарт AutoDock Vina), что гарантирует надежное сэмплирование конформаций для формирования качественной обучающей выборки.
* **Фильтрация Drug-likeness:**
  * Применен структурный фильтр по числу торсионных степеней свободы (**TORSDOF $\le$ 16**).
  * *Обоснование:* Классическое **правило Вебера (Veber's Rule)** рекомендует жесткое ограничение ($\le$ 10). Однако лимит был адаптирован до $\le$ 16, так как эффективные ингибиторы протеазы ВИЧ-1 исторически представляют собой крупные пептидомиметики. Это позволило сохранить релевантные молекулы, отсеяв избыточно гибкие соединения.

## 3. Этап II: Инженерия признаков (Feature Engineering)

* **Технологический стек:** RDKit, OpenBabel (`OBConversion`), хемоинформатика
* **Архитектура признакового описания:**
  Для обучения прогностических моделей трехмерные структуры лигандов ($PDBQT$) реконструировались в канонический формат SMILES и преобразовывались в гибридный признаковый вектор размерностью **1039 признаков**:
  * **Morgan Fingerprints (ECFP4):** **1024-битный** вектор топологического окружения атомов (радиус = 2), кодирующий молекулярную архитектуру и связность.
  * **Физико-химические дескрипторы (5 непрерывных величин):**
    * *Molecular Weight ($M_W$):* Молекулярная масса соединений (с ограничением профиля до 600 Да).
    * *LogP:* Расчетный коэффициент распределения октанол/вода для оценки липофильности.
    * *TPSA:* Топологическая полярная поверхность молекулы, определяющая ее мембранную проницаемость.
    * *H-Donors / H-Acceptors:* Количество доноров и акцепторов водородных связей для оценки электростатического взаимодействия с каталитической диадой $Asp25$/$Asp25'$.
  * **Фрагментные дескрипторы (10 специфических подструктур):**
    * Прямой подсчет вхождений ключевых функциональных групп: бензольные кольца, ароматический гидроксил ($Ar\text{-}OH$), аминогруппы (первичные/вторичные), амидные группы, сложные эфиры, карбоксильные группы, гетероароматический азот, кетоны и сульфонамиды.
    * *Обоснование:* Включение явных фрагментных дескрипторов повышает интерпретируемость моделей машинного обучения, позволяя соотносить вклад конкретных функциональных групп с изменением энергии Гиббса.

## 4. Этап III: Машинное обучение, оптимизация и сериализация моделей

* **Технологический стек:** Scikit-learn, CatBoost, Optuna, Joblib
* **Параметры датасета и базовая статистика:**
  * Общий объем валидной выборки: $N = 1196$ соединений.
  * Целевая переменная ($y$): Энергия Гиббса ($\Delta G$), рассчитанная в AutoDock Vina.
  * Диапазон: от $-12.514$ до $-0.615$ ккал/моль | Среднее: $-9.50$ ккал/моль | СКО: $1.03$ ккал/моль.
  * Разделение выборки: 80% Обучение ($n = 956$), 20% Отложенный тест ($n = 240$).

* **Двухэтапный отбор признаков (Feature Selection):**
  Для борьбы с размерностью и устранения мультиколлинеарности реализован последовательный пайплайн очистки данных:
  1. **VarianceThreshold:** Удаление константных и маловариативных бит-векторов сократило признаковое пространство с **1039** до **262**.
  2. **RFE (Recursive Feature Elimination):** Оберточный метод на базе рекурсивного исключения признаков выделил **120** наиболее значимых дескрипторов.

* **Протокол обучения и оптимизации:**
  Проведено сравнительное моделирование алгоритмов **Random Forest Regressor** и **CatBoost Regressor**. Подбор гиперпараметров осуществлялся методом Байесовской оптимизации на платформе **Optuna** ($50$ итераций, семплер `TPESampler`). Для предотвращения переобучения внутри оптимизационного цикла применена **5-блочная кросс-валидация (5-Fold CV)**.

* **Результаты тестирования моделей:**

| Метрика | Random Forest (Optuna) | CatBoost (Optuna) | Ансамбль (Blend) |
| :--- | :---: | :---: | :---: |
| **CV MAE** | 0.4622 | **0.4580** | — |
| **Test MAE (ккал/моль)** | 0.450 | **0.442** | 0.457 |
| **Test RMSE (ккал/моль)** | **0.625** | 0.632 | 0.638 |
| **Test $R^2$ Score** | **0.458** | 0.445 | 0.434 |

* **Интерпретация модели (Feature Importance):**
  Наибольший вклад в предсказательную способность алгоритма Random Forest вносят топологические фрагменты: **Morgan_Bit_232** (Относительная важность: $6.02\%$), **Morgan_Bit_237** ($3.85\%$) и **Morgan_Bit_233** ($2.90\%$), а также базовый гидрофобный дескриптор **LogP**, что подтверждает термодинамическую важность гидрофобных контактов лигандов в кармане протеазы ВИЧ-1.

* **Сериализация конвейера вывода (Inference Pipeline):**
  Ввиду того, что оптимизированная модель Random Forest показала наилучшую обобщающую способность на независимом тесте ($R^2 = 0.458$), она была выбрана в качестве финального предиктора. С целью обеспечения стабильной воспроизводимости инференса без искажения размерности входных векторов, с помощью библиотеки `joblib` экспортирован многокомпонентный артефакт:
  * `1_variance_selector.pkl` — маска фильтрации дисперсии.
  * `2_rfe_selector.pkl` — маска рекурсивного отбора RFE.
  * `hiv_protease_model.pkl` — финальные веса обученной модели Random Forest.

## 5. Этап IV: Анализ результатов, валидация и хемоинформационная дискуссия

* **Метрики обобщающей способности:**
  Финальная модель **Random Forest Regressor** продемонстрировала следующие показатели точности на независимой отложенной выборке ($20\%$ от исходного датасета):
  * **Средняя абсолютная ошибка (MAE):** **$0.450\text{ ккал/моль}$**. Это означает, что ИИ предсказывает энергию связывания с точностью до $\approx 0.45\text{ ккал/моль}$, что полностью укладывается во внутреннюю погрешность и аппаратный шум классических полуэмпирических функций скоринга молекулярного докинга ($\pm 0.5 \dots 1.0\text{ ккал/моль}$).
  * **Коэффициент детерминации ($R^2$ Score):** **$0.458$**. Подобный показатель может показаться умеренным в классическом Data Science, однако для задач структурной хемоинформатики данный результат является закономерным и биологически обоснованным в силу специфики архитектуры данных.

* **Хемоинформационный анализ полученных метрик:**
  * **Эффект смещения выборки (Narrow Dynamic Range):** Исходный датасет из ChEMBL изначально сформирован из соединений, целенаправленно тестировавшихся против ВИЧ. Из-за этого распределение целевой переменной сильно сжато в узком терапевтическом диапазоне (от $-12$ до $-6$ ккал/моль с медианой $-9.57$ ккал/моль). Модель решает сложную задачу — она ищет тонкие различия между «сильными» и «умеренными» ингибиторами, в выборке отсутствуют заведомо неактивные молекулы. Добавление случайного химического шума (заведомо не связывающихся веществ) искусственно завысило бы метрику $R^2$, но снизило бы реальную прогностическую ценность модели.
  * **Восстановление 3D-термодинамики по 2D-топологии:** Признаковое описание в основном базируется на плоских топологических фингерпринтах (Morgan Fingerprints), в то время как AutoDock Vina рассчитывает энергию на основе реальных трехмерных конформаций и геометрии кармана. Достижение средней ошибки (MAE) в $0.45\text{ ккал/моль}$ говорит о том, что алгоритм Random Forest успешно восстановил сложные пространственные закономерности SAR, несмотря на редукцию пространственной размерности.

* **Валидация «здравого смысла» модели (External Sanity Check):**
  Для верификации селективности обученного ИИ-конвейера и проверки его адекватности проведен бенчмаркинг на внешних соединениях, не входивших в обучающую выборку:

| Соединение | Фармакологический профиль / Аннотация | Прогноз ИИ ($\Delta G$, ккал/моль) |
| :--- | :--- | :---: |
| **Ритонавир** | Специфический высокоэффективный ингибитор протеазы ВИЧ-1 | **-9.48** |
| **Аспирин** | Неспецифический контроль (НПВП, ингибитор ЦОГ) | **-7.50** |
| **Кофеин** | Неспецифический контроль (стимулятор ЦНС) | **-6.52** |

* **Область применения конвейера и практический вывод:**
  Разработанная модель успешно справляется с задачей ранжирования (rank-ordering), отдавая безусловный термодинамический приоритет целевому клиническому препарату (**Ритонавир**) перед нерелевантными малыми молекулами (**Аспирин**, **Кофеин**). 

  Данный пайплайн является **узкоспециализированным предиктором**, разработанным для этапа **оптимизации лидерных соединений (Lead Optimization)**. Модель не предназначена для анализа случайных молекулярных библиотек общего профиля. Её фундаментальная задача — быстрый скрининг и ранжирование направленно модифицированных производных ингибиторов протеазы ВИЧ-1, что позволяет медикам-химикам эффективно отбирать кандидатов с наилучшим термодинамическим профилем без высоких вычислительных затрат на классический молекулярный докинг.


## 6. Руководство по использованию (Usage Guide)

Финальный скрипт инференса представляет собой универсальный инструмент командной строки, предназначенный для экспресс-оценки аффинности. Пайплайн автоматически распознает как канонические строки SMILES, так и пространственные форматы файлов (`.pdb`, `.pdbqt`), используя библиотеку OpenBabel для десериализации 3D-структур.

### Предварительные требования
Управление вычислительным окружением полностью автоматизировано через Conda/Mamba. Для сборки идентичной виртуальной среды (включая RDKit, OpenBabel и фиксированные версии ML-библиотек) выполните:

```bash
# Перейдите в корневую директорию проекта после клонирования
cd HIV1-Protease-ML-Discovery

# Разверните виртуальное окружение из конфигурационного файла
conda env create -f environment.yml

# Активируйте созданное окружение
conda activate structural
```

### Примеры запуска из терминала
> **ВАЖНОЕ ТРЕБОВАНИЕ:** Все команды запуска должны выполняться строго из **корневой директории репозитория** (`HIV1-Protease-ML-Discovery`). Запуск скриптов непосредственно из папки `src/` приведет к ошибке импорта, так как относительные пути к файлам в папке `models/` будут нарушены.

#### 1. Предсказание по строке SMILES
Для быстрой оценки конкретного соединения передайте его строку SMILES в качестве позиционного аргумента:
```bash
python ./src/predict.py "CC(C)C1=NC(=CS1)CN(C)C(=O)NC(C(C)C)C(=O)NC(CC2=CC=CC=C2)CC(C(CC3=CC=CC=C3)NC(=O)OCC4=CN=CS4)O"
```
*Пример вывода в консоль:*
```text
Загрузка ИИ-конвейера...
Все компоненты успешно загружены.
--- Обработка SMILES: CC(C)C1=NC(=CS1)CN(C)C(=O)NC(C(C)C)C(=O)... ---

[РЕЗУЛЬТАТ] Предсказанная энергия: -9.480 kcal/mol
```

#### 2. Анализ файлов молекулярных структур (.pdb / .pdbqt)
Пайплайн автоматически считывает файлы пространственной геометрии, конвертирует их метаданные и рассчитывает гибридный признаковый вектор. Передайте относительный или абсолютный путь к файлу:
```bash
python ./src/predict.py data/processed/sample_ligand.pdbqt
```
*Пример вывода в консоль:*
```text
Загрузка ИИ-конвейера...
Все компоненты успешно загружены.
--- Обработка файла: data/processed/sample_ligand.pdbqt ---

[РЕЗУЛЬТАТ] Предсказанная энергия: -10.125 kcal/mol
```

### Диагностика и обработка исключений
В CLI-утилите реализована строгая проверка корректности данных:
* **Верификация артефактов:** Скрипт контролирует наличие файлов `1_variance_selector.pkl`, `2_rfe_selector.pkl` и `hiv_protease_model.pkl` в целевой директории перед инициализацией весов предиктора.
* **Валидация форматов:** При попытке передать неподдерживаемое расширение или поврежденную SMILES-строку утилита прерывает выполнение с выводом соответствующего диагностического сообщения, предотвращая подачу пустых матриц на вход ИИ.
